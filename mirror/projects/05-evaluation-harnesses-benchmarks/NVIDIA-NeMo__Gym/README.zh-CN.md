# NeMo Gym

**[要求](#-要求)** • **[快速开始](#-快速开始)** • **[可用环境](#-可用环境)** • **[文档与资源](#-文档与资源)** • **[社区与支持](#-社区与支持)** • **[引用](#-引用)**

NeMo Gym 是一个用于构建大型语言模型（LLM）强化学习（RL）训练环境的库。它为环境开发、扩展 rollout 收集以及与首选训练框架的无缝集成提供基础设施。

## 🏆 为什么选择 NeMo Gym？

- 提供脚手架和模式以加速环境开发：多步、多轮和用户建模场景
- 无需掌握整个 RL 训练循环的专业知识即可贡献环境
- 可独立于 RL 训练循环，端到端地测试环境和吞吐量
- 与现有的环境、系统和 RL 训练框架互操作
- 不断增长的训练环境和数据集集合，用于可验证奖励的强化学习（RLVR）

> [!IMPORTANT]
> NeMo Gym 目前处于早期开发阶段。你可能会遇到不断演变的 API、不完整的文档和偶尔的错误。我们欢迎贡献和反馈——如有任何变更，请先开一个 issue 来发起讨论！

## 🔗 生态系统

NeMo Gym 是 [NVIDIA NeMo](https://docs.nvidia.com/nemo/gym/latest/about/ecosystem.html#related-nemo-libraries) 的一部分，NVIDIA NeMo 是 NVIDIA 用于构建和训练生成式 AI 模型的 GPU 加速平台。NeMo Gym 与越来越多的 RL 训练框架和环境库集成；详见[生态系统](https://docs.nvidia.com/nemo/gym/latest/about/ecosystem.html)页面获取完整详情和教程。

**训练框架：** [NeMo RL](https://docs.nvidia.com/nemo/gym/latest/training-tutorials/nemo-rl-grpo/index.html) • [OpenRLHF](https://github.com/OpenRLHF/OpenRLHF/blob/main/examples/python/agent_func_nemogym_executor.py) • [Unsloth](https://docs.nvidia.com/nemo/gym/latest/training-tutorials/unsloth-training.html) • [更多 →](https://docs.nvidia.com/nemo/gym/latest/about/ecosystem.html#training-framework-integrations)

**环境库：** [Reasoning Gym](https://github.com/NVIDIA-NeMo/Gym/tree/main/resources_servers/reasoning_gym) • [Aviary](https://github.com/NVIDIA-NeMo/Gym/tree/main/resources_servers/aviary) • [更多 →](https://docs.nvidia.com/nemo/gym/latest/about/ecosystem.html#environment-library-integrations)

## 📋 要求

NeMo Gym 旨在标准开发机器上运行：

| 硬件要求 | 软件要求 |
| --------------------- | --------------------- |
| **GPU**：NeMo Gym 库运行不需要 GPU<br>• 特定资源服务器或模型推理可能需要 GPU（参见各服务器文档） | **操作系统**：<br>• Linux（Ubuntu 20.04+ 或等效版本）<br>• macOS（x86_64 为 11.0+，Apple Silicon 为 12.0+）<br>• Windows（通过 WSL2） |
| **CPU**：任何现代 x86_64 或 ARM64 处理器（如 Intel、AMD、Apple Silicon） | **Python**：3.12 或更高版本 |
| **内存**：最低 8 GB（更大的环境推荐 16 GB+） | **Git**：用于克隆仓库 |
| **存储**：最低 5 GB 可用磁盘空间用于安装和基本使用 | **网络连接**：下载依赖和 API 访问所需 |

**额外要求**

- **API 密钥**：OpenAI API 密钥且有可用额度（用于快速入门示例）
  - 支持其他模型提供商（Azure OpenAI、通过 vLLM 的自托管模型）
- **Ray**：作为依赖自动安装（无需单独设置）

## 🚀 快速开始

安装 NeMo Gym，启动服务器，并收集你的第一批用于 RL 训练的验证 rollout。

### 设置
```bash
# 克隆仓库
git clone git@github.com:NVIDIA-NeMo/Gym.git
cd Gym

# 安装 UV（Python 包管理器）
curl -LsSf https://astral.sh/uv/install.sh | sh
source $HOME/.local/bin/env

# 创建虚拟环境
uv venv --python 3.12
source .venv/bin/activate

# 安装 NeMo Gym
uv sync --extra dev --group docs
```

### 配置你的 API Key
创建一个 `env.yaml` 文件，包含你的 OpenAI API Key 和你想要使用的[策略模型](https://docs.nvidia.com/nemo/gym/latest/about/concepts/key-terminology.html#term-Policy-Model)。将 `your-openai-api-key` 替换为你的实际密钥。此文件有助于让你的密钥避免被纳入版本控制，同时仍可供 NeMo Gym 使用。

```bash
echo "policy_base_url: https://api.openai.com/v1
policy_api_key: your-openai-api-key
policy_model_name: gpt-4.1-2025-04-14" > env.yaml
```

> [!NOTE]
> 我们在本快速入门中使用 GPT-4.1，因为它提供低延迟（无推理步骤）且开箱即用。NeMo Gym **不限于 OpenAI 模型**——你可以通过 vLLM 或任何兼容 OpenAI 的推理服务器使用自托管模型。详见[文档](https://docs.nvidia.com/nemo/gym/latest/get-started/detailed-setup.html)。

### 启动服务器

**终端 1（启动服务器）**：
```bash
# 启动服务器（将持续运行）
config_paths="resources_servers/example_single_tool_call/configs/example_single_tool_call.yaml,\
responses_api_models/openai_model/configs/openai_model.yaml"
ng_run "+config_paths=[${config_paths}]"
```

**终端 2（与代理交互）**：
```bash
# 在新终端中，激活环境
source .venv/bin/activate

# 与你的代理交互
python responses_api_agents/simple_agent/client.py
```

### 收集 Rollout

**终端 2**（保持终端 1 的服务器运行）：
```bash
# 创建一个包含单条查询的简单数据集
echo '{"responses_create_params":{"input":[{"role":"developer","content":"You are a helpful assistant."},{"role":"user","content":"What is the weather in Seattle?"}]}}' > weather_query.jsonl

# 收集验证 rollout
ng_collect_rollouts \
    +agent_name=example_single_tool_call_simple_agent \
    +input_jsonl_fpath=weather_query.jsonl \
    +output_jsonl_fpath=weather_rollouts.jsonl

# 查看结果
cat weather_rollouts.jsonl | python -m json.tool
```
这将生成带有验证分数的训练数据！

### 清理服务器

**终端 1** 中运行的服务器：按 Ctrl+C 停止 ng_run 进程。

### 后续步骤

现在你可以生成 rollout 了，选择你的路径：

- **开始训练** — 使用你喜欢的 RL 框架通过 NeMo Gym 训练模型。参见[训练教程](https://docs.nvidia.com/nemo/gym/latest/training-tutorials/index.html)。

- **使用现有环境** — 浏览下方的[可用环境](#-可用环境)，找到符合你目标的环境。

- **构建自定义环境** — 实现或集成现有工具并定义任务验证逻辑。从[创建训练环境](https://docs.nvidia.com/nemo/gym/latest/environment-tutorials/creating-training-environment.html)教程开始。
