OpenInference 是一组与 [OpenTelemetry](https://opentelemetry.io/) 互补的约定和插件，用于为 AI 应用启用追踪。OpenInference 由 [arize-phoenix](https://github.com/Arize-ai/phoenix) 原生支持，但同样可以与任何兼容 OpenTelemetry 的后端一起使用。

## 规范

OpenInference 规范由位于 [spec 目录](./spec/) 中的 Markdown 文件维护。其设计目标是为 LLM 调用以及周边应用上下文提供可观测性，例如从向量存储中检索，以及使用搜索引擎或 API 等外部工具。该规范与传输方式和文件格式无关，旨在与 JSON、ProtoBuf 和 DataFrames 等其他规范配合使用。

## Instrumentation

OpenInference 为多种语言中的常见机器学习 SDK 和框架提供了一组 instrumentation。

## 支持的目标端

OpenInference 支持以下目标端作为 span 收集器。

- ✅ [Arize Phoenix](https://github.com/Arize-ai/phoenix)
- ✅ [Arize AX](https://arize.com/)
- ✅ 任何兼容 OTEL 的收集器
